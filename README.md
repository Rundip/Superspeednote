# ⚡ Super Speed Note

메모장보다 빠르게 꺼내 쓰는 Windows용 노트 앱. 메모마다 전역 단축키를 붙여서, 어떤 프로그램을 쓰고 있든 그 메모를 바로 앞으로 불러오고, 같은 키를 한 번 더 누르면 방금 쓰던 창으로 돌아갑니다.

![logo](assets/logo_512.png)

## 실행

```
dist\SuperSpeedNote_<버전>.exe      (예: SuperSpeedNote_1.4.7.exe · 빌드하면 버전이 이름 끝에 붙음)
```

- **설치가 필요 없는 단일 실행 파일**(약 1.4MB)입니다. Windows 10/11에 기본으로 들어 있는 .NET Framework 4.8과 Edge WebView2 런타임만 사용합니다.
- 시작 메뉴에 등록하려면 `powershell -ExecutionPolicy Bypass -File install.ps1` (바탕화면 바로가기도 원하면 `-Desktop`)을 실행하세요.
- 설정(Ctrl+,) → **Windows 시작 시**에서 고릅니다:
  - **단축키 대기**(기본): 앱이 꺼져 있어도 메모 단축키를 누르면 열림. 대기 중 메모리 약 28MB.
  - **트레이 상주**: 언제나 즉시 열림. 메모리 약 220MB(웹 엔진 상주).
  - **창 열기**: 로그인하면 앱 창이 바로 열림.
  - **끔**: 자동으로 켜지지 않음.
  - Windows 시작 때는 `%LOCALAPPDATA%\Programs\SuperSpeedNote`에 둔 사본이 켜집니다(앱을 실행하면 그 사본을 최신으로 맞춤). 그래서 받은 exe를 옮기거나 이름을 바꾸거나 지워도 계속 자동으로 켜집니다.
- **새 버전 exe를 실행하면** 이전 버전이 트레이·대기 중이어도 저장하고 꺼진 뒤 새 버전이 이어서 켜집니다. 앱 이름 옆에 지금 버전(예: v1.4.2)이 보입니다.
- 닫기(X)는 트레이로 숨기기(즉시 다시 열림), **끄기**(Ctrl+Q / 트레이 메뉴)는 웹 엔진을 내리고 단축키만 대기, **완전 종료**는 트레이 메뉴.

## 속도 — 메모장과 비교 (이 PC 실측, 중앙값)

| 상황 | 창이 뜸 | 바로 입력 가능 |
|---|---|---|
| 메모장 실행 | 0.11초 | 0.14초 |
| Super Speed Note — 트레이 상주 중 단축키 | — | **0.026초** (해당 메모·커서 위치까지) |
| Super Speed Note — 꺼짐(단축키 대기) 중 단축키 | 0.08초 | 0.78초 |
| Super Speed Note — 완전히 꺼진 상태에서 실행 | 0.22초 | 0.98초 |

- 띄워 둔 상태(트레이)에서는 메모장을 새로 여는 것보다 약 5배 빠르고, 원하는 메모가 커서 위치까지 바로 열립니다. 완전히 꺼진 상태에서 새로 켤 때는 WebView2 엔진 기동(약 0.4초) 때문에 메모장이 더 빠릅니다.
- 창을 먼저 그리고, 그사이 엔진 기동과 메모 파일 읽기를 **동시에** 진행합니다. 화면은 프레임워크 없는 순수 JS 한 파일입니다.
- 저장은 입력이 멈춘 뒤 0.4초에 바뀐 메모 파일 하나만, 별도 스레드에서 원자적으로(임시 파일 → 교체) 기록합니다.

### 노트 개수와 크기 (실측)

노트 수(각 3KB)에 따른 동작 시간 — 보드·검색은 다시 그리지 않고 바뀐 카드만 갱신하며, 화면 밖 카드는 그리지 않습니다.

| 노트 수 | 보드 표시 | 검색 | 노트 열기 | 메모리 |
|---|---|---|---|---|
| 20 | 0.8ms | 0.2ms | 8ms | 238MB |
| 300 | 1.1ms | 2ms | 13ms | 288MB |
| 500 (최대) | 1.2ms | 4ms | 16ms | 318MB |
| 1000 | 2.4ms | 11ms | 23ms | 340MB |

노트 하나가 커지면 그 노트를 **열 때만** 느려집니다(다른 노트·단축키 호출에는 영향 없음).

| 노트 하나 크기 | 열기 |
|---|---|
| 50KB (약 2만 자) | 0.03초 |
| 150KB (약 6만 자) | 0.08초 |
| 300KB (약 12만 자) | 0.15초 |
| 1MB (약 40만 자) | 0.5초 |
| 5MB (약 200만 자) | 2.5초 |

전체 데이터 양은 앱을 새로 켤 때만 영향을 줍니다(전체 5MB일 때 약 +0.2초). 이미지는 메모와 별도 파일로 저장되므로 크기에 들어가지 않습니다.

## 기능

**메모 보드 / 목록 보기**
- 최대 500개 메모를 카드(제목 + 두 줄 미리보기)로 표시. 방향키로 선택, **더블클릭 또는 Enter**로 열기
- 보드 위 **[보드 | 목록]**으로 보기 방식 선택(기억됨). **목록**은 왼쪽에 메모 목록, 오른쪽에 마지막으로 본 메모. ↑/↓로 메모를 넘겨 보기만 하고(커서는 메모 안으로 들어가지 않음), Enter·클릭으로 이어 쓰기, 쓰다가 Esc = 목록으로
- 새 메모(Ctrl+N)는 본문부터 바로 입력. 제목을 비워 두면 첫 줄이 제목으로 표시
- F2 이름 바꾸기, Del 삭제(토스트에서 되돌리기), 드래그로 순서 변경(보드·목록 모두, 들어갈 자리에 막대가 표시됨), 고정(맨 앞), 카드 색상 8종
- 고정한 메모끼리는 **이름 순서**(기호 → 숫자(2가 10보다 앞) → 한글 ㄱ~ㅎ → 한자 → 영어 A~Z). 고정하지 않은 메모는 옮겨 놓은 순서 그대로
- Ctrl+1~9 바로 열기, Ctrl+K 빠른 이동(제목·내용 전체 검색, 제목이 맞는 메모가 먼저), 보드에서 바로 타이핑하면 검색. 둘 다 찾아 붙여넣기와 같은 규칙(여러 단어·초성·`-` 없는 숫자)이고, 내용으로 찾은 카드는 찾은 부분을 보여 줌

**전역 단축키**
- 메모마다 원하는 키 조합 지정(⌨ 단축키 지정 → 키를 누르기만 하면 됨)
- 누르면 그 메모가 맨 앞 창이 되고, 다시 누르면 **직전에 선택돼 있던 창**(다른 프로그램이든 다른 메모든)으로 돌아감. 트레이에 숨어 있었다면 다시 숨김
- 앱 전체 호출 키(기본 Ctrl+Alt+N)도 같은 방식으로 동작. 앱이 꺼져 있어도(단축키 대기) 동작
- Windows 기본 단축키와 겹치면 지정할 때 경고(Win+D, F5, Ctrl+F 등). 복사·붙여넣기·Alt+Tab·Win+L처럼 꼭 필요한 키는 막음. 다른 프로그램이 이미 쓰는 조합이면 빨갛게 표시하고 알림

**한 줄 찾아 바로 붙여넣기 (Ctrl+Alt+F, 앱 안에서는 Ctrl+Shift+F)**
- 어떤 프로그램을 쓰다가 눌러도 **그 창 위에 작은 검색창**이 바로 뜸(앱 창은 그대로 숨어 있음). 모든 메모를 **한 줄 단위**로 찾음
- **Enter** = 원래 창의 커서 자리에 바로 붙여넣기 · **Shift+Enter** = 복사만 · **Ctrl+Enter** = 그 메모의 그 줄 열기 · **Esc**(또는 단축키 한 번 더) = 그냥 돌아가기 · 다른 곳을 클릭하면 닫힘
- 앱 안에서 연 검색창(Ctrl+Shift+F): **Alt+Enter** = 지금 쓰는 메모의 커서 자리에 넣기 · **Ctrl+C** = 복사만 하고 앱에 그대로 · Enter / Shift+Enter는 이전 창으로 돌아가서 붙여넣기 / 복사
- **메모 제목만으로도 찾음**: 제목에 그 단어가 있는 메모의 줄들이 (단어가 들어 있는 줄들 다음에) 나옴
- 띄어쓰기로 단어를 더 넣으면 좁혀짐. 나머지 단어는 **메모 제목, 위쪽 제목(#), 표의 열 이름**에 있어도 됨. 열 이름으로 찾으면 그 칸이 미리 골라져서 `대한물산 계좌` → Enter = 계좌번호만 붙여넣기 (`한빛 전화`도 마찬가지)
- **초성 검색**: `ㄱㅊㅅ` → 김철수 (`ㅄ`처럼 IME가 합친 자음도 됨) · 전화·계좌번호는 `-` 없이 숫자만 넣어도 찾음 (`021234` → 02-1234-5678)
- **Tab / Shift+Tab** = 표의 행이면 **칸 하나만**, 일반 줄이면 `전화: 010-…`의 값이나 단어 하나만 골라 붙여넣기. 고른 칸의 열 이름과 몇 번째인지(2/4)가 함께 보임. `전화`처럼 이름표로 찾은 줄은 값이 미리 골라져 있음
- **마우스로 고르기**: 오른쪽 미리보기의 '골라서 붙여넣기'(줄 전체 · 칸 · 단어)나 표의 값을 클릭하면 그것만 붙여넣기, Shift+클릭은 복사만
- **Alt+1~9** = N번째 결과 바로 붙여넣기
- 빈 검색창 = **최근 붙여넣은 줄** (마지막에 고른 칸까지 기억). 자주 붙여넣는 줄일수록 위로. 메모에서 그 줄이 바뀌거나 지워지면 목록에서도 빠져서 옛날 값이 붙는 일이 없음
- 오른쪽 미리보기에 그 줄 앞뒤 내용과 표의 열 이름이 보여서 붙여넣기 전에 확인 가능
- 속도: 줄 목록은 쉬는 동안 미리 만들어 둠. 메모 500개 · 2만 1천 줄에서 검색 2~9ms(한 화면 프레임 이내). 단축키 → 검색창 표시 약 0.05초(단축키 대기 상태에서는 첫 호출 약 0.9초)
- 기본 키가 다른 프로그램과 겹치면(예: Claude 데스크톱 앱이 Ctrl+Alt+Space 사용) 비어 있는 다른 조합으로 자동 지정하고 알려 줌

**빠른 메모 (Ctrl+Alt+M)**
- 어떤 프로그램을 쓰다가 눌러도 **지금 쓰는 화면의 모서리에 작은 메모창**이 뜨고 바로 입력(기본 오른쪽 아래 · 설정 › 실행 › 빠른 메모 위치에서 네 모서리 중 선택, 배율이 다른 모니터에서도 정확히 모서리에). 누를 때마다 **새 메모**(목록 맨 앞에 생김), 자동 저장
- 다른 창에서 일해도 **항상 위에 떠 있음**. 다른 창에 있을 때 단축키를 누르면 메모로 돌아오고, 메모에서 누르면(또는 **Esc**, **X**) 닫히고 쓰던 창의 커서로 돌아감. 아무것도 안 쓰고 닫으면 빈 메모는 남기지 않음
- 굵게·형광펜·체크리스트·표 붙여넣기 등 편집 단축키 그대로. 메모창 안에서 **Ctrl+Alt+F**(또는 Ctrl+Shift+F)로 다른 메모의 줄을 찾아 **메모에 바로 넣기**(앞 글자와 띄어서, 표의 행은 빈 줄이면 표로 · 아니면 `한빛상사 · 김철수 과장 · …` 한 줄로. Shift+Enter = 복사만)
- 메모창 위쪽 막대를 끌어 옮기고, 가장자리를 끌어 크기 조절(크기는 기억). **↗** 버튼이나 앱 단축키(Ctrl+Alt+N)로 앱을 열면 그 메모를 앱에서 이어서 씀. 다른 메모로 가는 키(Ctrl+N, Ctrl+K, Ctrl+1~9 등)는 메모창에서는 막혀 있고 누르면 알려 줌
- 앱 안에 있을 때 누르면 그냥 새 메모. 단축키 대기 상태에서도 첫 호출 약 0.7초

**꺼내 쓰기**
- **Ctrl+Shift+Enter**: 복사 → 원래 쓰던 창으로 돌아가서 바로 붙여넣기
- **Ctrl+Shift+C**: 복사 → 원래 창으로 돌아가기
- 보내는 내용: 선택한 글 > 선택한 칸 > 현재 줄 (보드·제목에서는 메모 전체). 표는 엑셀에 그대로 붙는 형식
- 보드: 카드의 복사 버튼 또는 Ctrl+C로 메모 전체 복사
- Ctrl+K로 내용을 검색해 열면 그 단어 위치로 바로 이동·강조하고, 커서는 그 단어 바로 뒤(바로 이어서 입력 가능)

**표 (엑셀처럼)**
- 클릭·방향키로 칸 선택, Shift+방향키/드래그로 범위 선택, 선택한 칸에서 바로 입력하면 새 값으로 덮어쓰기 (한글 첫 글자도 자모가 갈라지지 않음)
- F2·더블클릭으로 편집(커서는 내용 끝), 편집 중 Esc = 취소, Delete = 지우기, Ctrl+A = 모든 칸(한 번 더 누르면 메모 전체)
- Enter = 아래 칸(마지막 행이면 행 추가), Tab = 다음 칸(**마지막 열이면 열 추가** · Tab 다음의 Enter도 바로 아래 칸으로), Shift+Enter / Alt+Enter = 칸 안 줄바꿈, Ctrl+Enter = 표 빠져나가기
- **중간에 행·열 넣기**: 표 왼쪽 여백(행)·위쪽 여백(열)에 마우스를 대면 가장 가까운 경계에 **+**가 나타남 → 클릭
- **끝에 행·열 추가**: 표 아래·오른쪽 가장자리 전체가 **+ 막대**. 아무 데나 클릭하면 하나, **끌면 미리보기만큼 여러 개**
- **끝의 빈 행·열 지우기**: 그 **+ 막대를 표 쪽으로** 끌면 끝에 있는 빈 행·열이 빨갛게 표시되고, 놓으면 지워짐. 내용이 있는 행·열 앞에서 멈춤 (Ctrl+Z로 되돌리기)
- 단축키: 위/아래에 행 삽입 Alt+Shift+↑/↓, 왼쪽/오른쪽에 열 삽입 Alt+Shift+←/→, 행 삭제 Ctrl+Shift+-, 열 삭제 Ctrl+Alt+- (여러 칸을 선택했으면 그 행·열 모두). 오른쪽 클릭 메뉴에도 같은 항목
- **엑셀·구글시트에서 복사한 셀 붙여넣기 → 표**. 병합된 셀은 풀어서(값은 왼쪽 위 칸에) 줄이 밀리지 않음. 범위 복사·붙여넣기는 선택한 사각형 그대로(밀림 없음), 값 하나는 선택한 칸 전체에
- 칸을 선택한 채 굵게·글자색·형광펜을 누르면 칸 전체에 적용

**서식**
- 굵게(Ctrl+B), 밑줄(Ctrl+U), 기울임, 취소선
- **형광펜** 6색과 '형광펜 없음'(Ctrl+Shift+H로 켜고 끄기). 메뉴에서 고른 펜(색 또는 없음)은 다시 고를 때까지 유지되고 툴바 막대에 보임 · 펜이 '없음'이면 버튼이 형광펜을 지움
- **잘 보이는 글자색** 검정 + 7색(흰 배경 대비를 기준으로 고름, 다크 테마에서는 밝은 색으로 자동 대응). 고른 색은 다시 고를 때까지 A 버튼의 색으로 유지
- 제목 1~3, 인용, 코드 블록, 글머리/번호 목록, 체크리스트, 구분선, 날짜·시간 넣기(Ctrl+;)
- **목록 단계 올리고 내리기**: Tab = 한 단계 안으로, Shift+Tab = 한 단계 밖으로. 하위 줄 맨 앞에서 **Backspace = 기호 그대로 한 단계 위로**(위 단계의 다음 번호가 되고 아래 줄들은 그 밑으로), 빈 하위 줄에서 **Enter = 한 단계 위로**. 최상위 줄 맨 앞의 Backspace는 기호만 지우고(번호는 이어짐), 한 번 더 누르면 일반 줄
- 줄 맨 앞에서 `#`, `-`, `1.`, `[]`, `>`, ```` ``` ```` + Space, `---` + Enter 로 빠른 서식
- 스크린샷 붙여넣기·이미지 드래그(이미지는 별도 파일로 저장해 메모가 무거워지지 않음)
- **이미지 크기 조절**: 그림을 클릭하면 오른쪽 가장자리·모서리에 손잡이가 생김 → 끌어서 크기 조절(비율 유지, Ctrl+Z로 되돌리기). 오른쪽 클릭 › 작게 / 중간 / 원래 크기도 됨
- **개체 선택 후 삭제**: 그림·구분선은 클릭, 표는 왼쪽 위 손잡이(또는 오른쪽 클릭 › 표 통째로 선택)로 선택 → Delete / Backspace로 삭제(실행 취소 가능), Esc로 선택 해제
- 링크 자동 변환, Ctrl+클릭으로 열기

**그 밖에**
- 메모 안 찾기(Ctrl+F, 다음/이전 F3 · Shift+F3, 없으면 '결과 없음'). 찾은 값이 표 안에 있으면 그 칸을 **오른쪽 클릭 = 칸 값 복사**, 실행 취소/다시(Ctrl+Z / Ctrl+Y · Ctrl+Shift+Z): 워드처럼 **단어 하나(띄어쓰기까지)** 씩, 입력과 지우기는 따로, 커서를 옮기면 새 단계, 서식·표·붙여넣기는 한 번에 하나씩. 되돌리면 커서가 그 자리로, 확대/축소(Ctrl+휠 · 70~200% 단계, 100%가 아닐 때만 상태 표시줄에 표시)
- 메모 안에서 F2 = 제목 고치기(비워 두면 첫 줄이 제목, 입력칸에 회색으로 보임). 글을 선택하면 상태 표시줄에 선택한 글자 수
- 사이드바 메모 목록: 클릭하면 그 메모가 열리고 키는 목록에 남음. **Del = 삭제**(확인 창 · Del 한 번 더 또는 [삭제], 휴지통으로 · 다음 메모가 열림), ↑/↓ 메모 이동(보기만, 표 안의 커서는 그대로), Enter·Tab 또는 아무 글자 = 다시 쓰기, Esc = 보드(목록 보기에서는 목록이 처음 화면)
- 라이트 / 다크 네이비 테마, 에디터 글꼴 선택, 항상 위에 표시
- 창 가장자리를 **더블클릭하면 그 방향으로 화면 끝까지** 늘어남(모서리는 두 방향), 한 번 더 더블클릭하면 원래대로
- 메모별 커서·스크롤 위치 기억
- 텍스트로 복사, .txt / .html 내보내기(이미지는 HTML 안에 포함)
- **여러 줄을 복사하면 글머리·번호·체크 상자가 글자로** 함께 복사됨(`1. ` `가. ` `• ` `☐ `, 단계마다 띄어쓰기 4칸) → 워드·한글·노션에 붙여넣어도 보이는 그대로. 한 줄만 복사하면 기호 없이 내용만
- **끌어서 넣기 · 꺼내기**: 텍스트·HTML 파일(.txt .md .csv .html …)을 앱 아무 데나 끌어다 놓으면 파일 이름으로 된 메모가 됩니다(UTF-8·한글 윈도우(CP949) 자동 인식 · 메모 하나에 약 100만 자까지 · 같은 파일을 두 번 넣으면 알려 줌). 앱에서 꺼낸 파일을 다시 넣으면 체크리스트·글자색·형광펜·머리글 행까지 그대로 돌아옵니다. 열린 메모에 그림과 텍스트 파일을 같이 놓으면 그림은 메모에, 파일은 새 메모로. 보드의 카드나 왼쪽 목록의 메모를 바탕화면·탐색기 폴더로 끌어다 놓으면 메모 이름으로 된 파일이 생깁니다(설정 › 데이터에서 HTML / 텍스트 선택 · 메일에 놓으면 첨부 파일). 앱이 직접 파일을 만들어 끌어 주는 방식이라 다운로드 창은 뜨지 않습니다
- 자동 저장 + 매일 자동 백업(최근 14일)
- **휴지통**(보드 위 휴지통 버튼 · 설정 › 일반): 삭제한 메모를 삭제한 날짜·첫 줄과 함께 보여 주고 **복원**하면 원래 자리·제목·색·고정·단축키까지 그대로 돌아옴. 하나씩 **영구 삭제**, **휴지통 비우기**(두 번 눌러 확인). 비우기 전까지 기한 없이 보관. 휴지통 목록은 열 때만 읽어서 평소 속도에는 영향 없음
- **빈 메모는 휴지통에 남기지 않고 바로 영구 삭제** (아무것도 안 쓰고 닫은 빠른 메모 포함)
- 단축키 전체 보기: **F1**

**단축키 바꾸기 (설정 › 단축키)**
- 전역 단축키(앱 부르기, 한 줄 찾아 붙여넣기, 메모별 단축키)와 **앱 안의 단축키 42가지**(새 메모, 빠른 이동, 찾기, 꺼내 쓰기, 굵게·밑줄·형광펜·목록·표·행/열 삽입·삭제·제목 1~3 등)를 모두 원하는 키로 지정
- 기본값이 없는 동작(글자색, 구분선, 제목 1~3, 테마 전환, 항상 위 등)에도 키를 붙일 수 있음
- 이미 다른 동작에 쓰는 키를 고르면 알려 주고 이쪽으로 옮김. 전역 단축키와 같은 키, 복사·붙여넣기·실행 취소처럼 꼭 필요한 키는 막음
- 동작별 ↺ 기본값으로, 한 번에 모두 기본값으로(되돌리기 가능). 툴바 툴팁·도움말(F1)·화면 안내가 바꾼 키로 함께 바뀜

## 데이터 위치

- 메모: `%APPDATA%\SuperSpeedNote\` (`state.json`, `notes\*.html`, `notes-meta.json`(메모 이름·색·순서 보관용), `images\`, `backups\`, `trash\`)
- 메모 파일: 앱이 쓰는 원본은 예전 그대로 `notes\<id>.html`(파일 이름은 바뀌지 않는 고유 id)이라 **이전 버전으로 되돌려도 그대로 열립니다**. 1.4.8부터 `메모\` 읽기용 사본 폴더는 더 쓰지 않습니다(예전 버전이 만든 폴더는 남아 있어도 되고 지워도 됨). 여러 버전을 번갈아 써도 목록에서 빠진 메모는 다음 실행 때 이름·색·순서 그대로 돌아오고, 다른 버전이 휴지통에 넣은 메모는 빈 메모로 되살아나지 않습니다. 긴 메모가 한 번에 크게 줄어들면 줄기 전 내용을 `backups\overwritten`에 보관합니다. 파일을 읽지 못한 메모는 읽기 전용으로 열려 덮어쓰지 않습니다
- **업데이트해도 메모는 그대로입니다.** 메모는 exe와 다른 폴더에 있고, 새 버전이 처음 실행될 때 `backups\before-<버전>`에 전체 사본을 먼저 만듭니다. `build.ps1`/`install.ps1`은 실행 중인 앱에 저장 후 종료를 요청한 뒤 exe를 바꿉니다.
- 메모 목록(`state.json`)은 저장할 때마다 직전 사본(`state.json.bak`)을 남기고, 손상되면 자동으로 복구합니다.
- 삭제한 메모는 `trash\`로 옮겨질 뿐 지워지지 않습니다.
- exe 옆에 `data` 폴더를 만들어 두면 그 폴더를 쓰는 **포터블 모드**로 동작합니다(USB 등).

## 빌드

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

- Windows에 내장된 C# 컴파일러(`csc.exe`, .NET Framework 4.x)를 씁니다. 별도 SDK 설치가 필요 없습니다.
- 첫 빌드 때 nuget.org에서 Microsoft WebView2 SDK 패키지(약 9MB)를 한 번 받아 `packages\`에 둡니다.
- WebView2 DLL과 화면(`src/ui/index.html`)은 exe 안에 포함됩니다. 아이콘(`assets\app.ico`, 로고 PNG)은 `tools\IconGen.cs`가 바뀌면 빌드할 때 자동으로 다시 그립니다. 강제로 다시 만들려면 `-Icon` 옵션을 붙이세요.
- 화면만 브라우저에서 미리 보려면 `node tools/devserver.js` → http://127.0.0.1:5178 (데이터는 localStorage에 저장).

## Microsoft Store 버전 (MSIX)

```
powershell -ExecutionPolicy Bypass -File package.ps1
```

- `dist\store\SuperSpeedNote_<버전>_x64.msix`를 만듭니다. Partner Center에 이 파일을 올리면 **Store가 무료로 서명**합니다(인증서 구입 필요 없음).
- 첫 실행 때 nuget.org에서 Microsoft Windows SDK 빌드 도구(약 21MB, makeappx·makepri)를 한 번 받아 `packages\`에 둡니다.
- Store 버전은 메모를 앱 전용 폴더(`%LOCALAPPDATA%\Packages\Mukhodeveloper.Superspeednote_…\LocalState`)에 저장합니다(제한된 기능은 runFullTrust뿐). 처음 실행할 때 이 PC에 exe 버전 메모가 있으면 한 번 복사해 오고, 그 뒤로는 따로 저장됩니다. 앱을 제거하면 메모도 지워지니 옮길 때는 설정 › 데이터 폴더에서 복사해 두세요.
- Windows 시작 시 '단축키 대기'로 켜지는 것은 Store의 시작 작업이 맡습니다(작업 관리자 › 시작 앱에서 켜고 끄기). Store 버전이 처음 실행되면 exe 버전이 등록해 둔 시작 항목은 지웁니다(둘 다 켜지지 않게).
- 로컬 테스트: `package.ps1 -Register`(개발자 모드 필요) → 시작 메뉴에서 실행, 끝나면 `package.ps1 -Unregister`.

**등록 순서**
1. https://storedeveloper.microsoft.com 에서 개인 개발자로 가입(무료, Microsoft 계정·본인 확인).
2. Partner Center에서 앱 이름 `Super Speed Note` 예약 → **제품 관리 › 제품 ID**의 `Package/Identity/Name`, `Package/Identity/Publisher`, `Package/Properties/PublisherDisplayName` 세 값을 `store\store.json`에 붙여넣기.
3. `package.ps1` 다시 실행 → 새 `.msix`를 **패키지** 단계에 업로드.
4. **스토어 등록 정보**: `store\listing-ko.md`의 설명·기능·키워드를 붙여넣고 `store\screenshots\`의 이미지 업로드. 개인정보 처리방침 URL은 `PRIVACY.md`의 GitHub 주소.
5. **제출 옵션**: `runFullTrust` 사용 이유(영문)를 `store\listing-ko.md`에서 붙여넣기 → 제출. 심사는 보통 며칠 걸립니다. 지원 연락처는 이메일(GitHub 링크 불가).
