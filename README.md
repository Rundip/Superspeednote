# ⚡ Super Speed Note

메모장보다 빠르게 꺼내 쓰는 Windows용 노트 앱. 메모마다 전역 단축키를 붙여서, 어떤 프로그램을 쓰고 있든 그 메모를 바로 앞으로 불러오고, 같은 키를 한 번 더 누르면 방금 쓰던 창으로 돌아갑니다.

![logo](assets/logo_512.png)

## 실행

```
dist\SuperSpeedNote.exe
```

- **설치가 필요 없는 단일 실행 파일**(약 1.4MB)입니다. Windows 10/11에 기본으로 들어 있는 .NET Framework 4.8과 Edge WebView2 런타임만 사용합니다.
- 시작 메뉴에 등록하려면 `powershell -ExecutionPolicy Bypass -File install.ps1` (바탕화면 바로가기도 원하면 `-Desktop`)을 실행하세요.
- 설정(Ctrl+,) → **Windows 시작 시**에서 고릅니다:
  - **단축키 대기**(기본): 앱이 꺼져 있어도 메모 단축키를 누르면 열림. 대기 중 메모리 약 28MB.
  - **트레이 상주**: 언제나 즉시 열림. 메모리 약 220MB(웹 엔진 상주).
- 닫기(X)는 트레이로 숨기기(즉시 다시 열림), **끄기**(Ctrl+Q / 트레이 메뉴)는 웹 엔진을 내리고 단축키만 대기, **완전 종료**는 트레이 메뉴.

## 속도 — 메모장과 비교 (이 PC 실측, 중앙값)

| 상황 | 창이 뜸 | 바로 입력 가능 |
|---|---|---|
| 메모장 실행 | 0.11초 | 0.14초 |
| Super Speed Note — 트레이 상주 중 단축키 | — | **0.026초** (해당 메모·커서 위치까지) |
| Super Speed Note — 꺼짐(단축키 대기) 중 단축키 | 0.08초 | 0.78초 |
| Super Speed Note — 완전히 꺼진 상태에서 실행 | 0.22초 | 0.98초 |

- 띄워 둔 상태(트레이)에서는 메모장을 새로 여는 것보다 약 5배 빠르고, 원하는 메모가 커서 위치까지 바로 열립니다. 완전히 꺼진 상태에서 새로 켤 때는 WebView2 엔진 기동(약 0.4초) 때문에 메모장이 더 빠릅니다.
- 창을 먼저 그리고, 그사이 엔진 기동과 메모 파일 읽기를 **동시에** 진행합니다. 화면은 프레임워크 없는 순수 JS 한 파일입니다.
- 저장은 입력이 멈춘 뒤 0.4초에 바뀐 메모 파일 하나만, 별도 스레드에서 원자적으로(임시 파일 → 교체) 기록합니다.

## 기능

**메모 보드**
- 최대 500개 메모를 카드(제목 + 첫 20글자)로 표시. 방향키로 선택, **더블클릭 또는 Enter**로 열기
- 새 메모(Ctrl+N)는 본문부터 바로 입력. 제목을 비워 두면 첫 줄이 제목으로 표시
- F2 이름 바꾸기, Del 삭제(토스트에서 되돌리기), 드래그로 순서 변경, 고정(맨 앞), 카드 색상 8종
- Ctrl+1~9 바로 열기, Ctrl+K 빠른 이동(제목·내용 전체 검색), 보드에서 바로 타이핑하면 검색

**전역 단축키**
- 메모마다 원하는 키 조합 지정(⌨ 단축키 지정 → 키를 누르기만 하면 됨)
- 누르면 그 메모가 맨 앞 창이 되고, 다시 누르면 **직전에 선택돼 있던 창**(다른 프로그램이든 다른 메모든)으로 돌아감. 트레이에 숨어 있었다면 다시 숨김
- 앱 전체 호출 키(기본 Ctrl+Alt+N)도 같은 방식으로 동작. 앱이 꺼져 있어도(단축키 대기) 동작
- Windows 기본 단축키와 겹치면 지정할 때 경고(Win+D, F5, Ctrl+F 등). 복사·붙여넣기·Alt+Tab·Win+L처럼 꼭 필요한 키는 막음. 다른 프로그램이 이미 쓰는 조합이면 빨갛게 표시하고 알림

**한 줄 찾아 바로 붙여넣기 (Ctrl+Alt+F, 앱 안에서는 Ctrl+Shift+F)**
- 어떤 프로그램을 쓰다가 눌러도 **그 창 위에 작은 검색창**이 바로 뜸(앱 창은 그대로 숨어 있음). 모든 메모를 **한 줄 단위**로 찾음
- **Enter** = 원래 창의 커서 자리에 바로 붙여넣기 · **Shift+Enter** = 복사만 · **Ctrl+Enter** = 그 메모의 그 줄 열기 · **Esc**(또는 단축키 한 번 더) = 그냥 돌아가기 · 다른 곳을 클릭하면 닫힘
- 띄어쓰기로 단어를 더 넣으면 좁혀짐. 나머지 단어는 **메모 제목, 위쪽 제목(#), 표의 열 이름**에 있어도 됨 (예: `한빛 전화`, `대한물산 계좌`)
- **초성 검색**: `ㄱㅊㅅ` → 김철수
- **Tab / Shift+Tab** = 표의 행이면 **칸 하나만**, 일반 줄이면 `전화: 010-…`의 값이나 단어 하나만 골라 붙여넣기. 고른 칸의 열 이름이 함께 보임
- **Alt+1~9** = N번째 결과 바로 붙여넣기
- 빈 검색창 = **최근 붙여넣은 줄** (마지막에 고른 칸까지 기억). 자주 붙여넣는 줄일수록 위로. 메모에서 그 줄이 바뀌거나 지워지면 목록에서도 빠져서 옛날 값이 붙는 일이 없음
- 오른쪽 미리보기에 그 줄 앞뒤 내용과 표의 열 이름이 보여서 붙여넣기 전에 확인 가능
- 속도: 줄 목록은 쉬는 동안 미리 만들어 둠. 메모 500개 · 2만 1천 줄에서 검색 2~9ms(한 화면 프레임 이내). 단축키 → 검색창 표시 약 0.05초(단축키 대기 상태에서는 첫 호출 약 0.9초)
- 기본 키가 다른 프로그램과 겹치면(예: Claude 데스크톱 앱이 Ctrl+Alt+Space 사용) 비어 있는 다른 조합으로 자동 지정하고 알려 줌

**빠른 메모 (Ctrl+Alt+M)**
- 어떤 프로그램을 쓰다가 눌러도 **화면 오른쪽 아래에 작은 메모창**이 뜨고 바로 입력. 누를 때마다 **새 메모**(목록 맨 앞에 생김), 자동 저장
- 다른 창에서 일해도 **항상 위에 떠 있음**. 단축키를 **한 번 더** 누르거나 **X**를 누르면 닫히고, 쓰던 창의 커서로 돌아감. 아무것도 안 쓰고 닫으면 빈 메모는 남기지 않음
- 굵게·형광펜·체크리스트·표 붙여넣기 등 편집 단축키 그대로. 메모창 안에서 **Ctrl+Alt+F**(또는 Ctrl+Shift+F)로 다른 메모의 줄을 찾아 **메모에 바로 넣기**
- 메모창 위쪽 막대를 끌어 옮기고, 가장자리를 끌어 크기 조절(크기는 기억). **↗** 버튼이나 앱 단축키(Ctrl+Alt+N)로 앱을 열면 그 메모를 앱에서 이어서 씀
- 앱 안에 있을 때 누르면 그냥 새 메모. 단축키 대기 상태에서도 첫 호출 약 0.7초

**꺼내 쓰기**
- **Ctrl+Shift+Enter**: 복사 → 원래 쓰던 창으로 돌아가서 바로 붙여넣기
- **Ctrl+Shift+C**: 복사 → 원래 창으로 돌아가기
- 보내는 내용: 선택한 글 > 선택한 칸 > 현재 줄 (보드·제목에서는 메모 전체). 표는 엑셀에 그대로 붙는 형식
- 보드: 카드의 복사 버튼 또는 Ctrl+C로 메모 전체 복사
- Ctrl+K로 내용을 검색해 열면 그 단어 위치로 바로 이동·강조

**표 (엑셀처럼)**
- 클릭·방향키로 칸 선택, Shift+방향키/드래그로 범위 선택, 선택한 칸에서 바로 입력하면 새 값으로 덮어쓰기
- F2·더블클릭으로 편집(커서는 내용 끝), 편집 중 Esc = 취소, Delete = 지우기, Ctrl+A = 표 전체
- Enter = 아래 칸(마지막 행이면 행 추가), Tab = 다음 칸, Shift+Enter = 칸 안 줄바꿈(편집 중), Ctrl+Enter = 표 빠져나가기
- 표 바깥 네 방향의 작은 **+ 버튼**으로 행·열 추가, 오른쪽 클릭으로 삽입·삭제·머리글
- **엑셀·구글시트에서 복사한 셀 붙여넣기 → 표**. 범위 복사·붙여넣기는 선택한 사각형 그대로(밀림 없음), 값 하나는 선택한 칸 전체에
- 칸을 선택한 채 굵게·글자색·형광펜을 누르면 칸 전체에 적용

**서식**
- 굵게(Ctrl+B), 밑줄(Ctrl+U), 기울임, 취소선
- **형광펜** 6색(Ctrl+Shift+H로 켜고 끄기)
- **잘 보이는 글자색** 7색(흰 배경 대비를 기준으로 고름, 다크 테마에서는 밝은 색으로 자동 대응)
- 제목 1~3, 인용, 코드 블록, 글머리/번호 목록, 체크리스트, 구분선, 날짜·시간 넣기(Ctrl+;)
- 줄 맨 앞에서 `#`, `-`, `1.`, `[]`, `>`, ```` ``` ```` + Space, `---` + Enter 로 빠른 서식
- 스크린샷 붙여넣기·이미지 드래그(이미지는 별도 파일로 저장해 메모가 무거워지지 않음)
- 링크 자동 변환, Ctrl+클릭으로 열기

**그 밖에**
- 메모 안 찾기(Ctrl+F), 실행 취소/다시(표 편집 포함), 확대/축소(Ctrl+휠)
- 라이트 / 다크 네이비 테마, 에디터 글꼴 선택, 항상 위에 표시
- 메모별 커서·스크롤 위치 기억
- 텍스트로 복사, .txt / .html 내보내기(이미지는 HTML 안에 포함)
- 자동 저장 + 매일 자동 백업(최근 14일)
- **휴지통**(보드 위 휴지통 버튼 · 설정 › 일반): 지운 메모를 지운 날짜·첫 줄과 함께 보여 주고 **복원**하면 원래 자리·제목·색·고정·단축키까지 그대로 돌아옴. 하나씩 **영구 삭제**, **휴지통 비우기**(두 번 눌러 확인). 비우기 전까지 기한 없이 보관. 휴지통 목록은 열 때만 읽어서 평소 속도에는 영향 없음
- **빈 메모는 휴지통에 남기지 않고 바로 영구 삭제** (아무것도 안 쓰고 닫은 빠른 메모 포함)
- 단축키 전체 보기: **F1**

**단축키 바꾸기 (설정 › 단축키)**
- 전역 단축키(앱 부르기, 한 줄 찾아 붙여넣기, 메모별 단축키)와 **앱 안의 단축키 36가지**(새 메모, 빠른 이동, 찾기, 꺼내 쓰기, 굵게·밑줄·형광펜·목록·표·제목 1~3 등)를 모두 원하는 키로 지정
- 기본값이 없는 동작(글자색, 구분선, 제목 1~3, 테마 전환, 항상 위 등)에도 키를 붙일 수 있음
- 이미 다른 동작에 쓰는 키를 고르면 알려 주고 이쪽으로 옮김. 전역 단축키와 같은 키, 복사·붙여넣기·실행 취소처럼 꼭 필요한 키는 막음
- 동작별 ↺ 기본값으로, 한 번에 모두 기본값으로(되돌리기 가능). 툴바 툴팁·도움말(F1)·화면 안내가 바꾼 키로 함께 바뀜

## 데이터 위치

- 메모: `%APPDATA%\SuperSpeedNote\` (`state.json`, `notes\*.html`, `images\`, `backups\`, `trash\`)
- **업데이트해도 메모는 그대로입니다.** 메모는 exe와 다른 폴더에 있고, 새 버전이 처음 실행될 때 `backups\before-<버전>`에 전체 사본을 먼저 만듭니다. `build.ps1`/`install.ps1`은 실행 중인 앱에 저장 후 종료를 요청한 뒤 exe를 바꿉니다.
- 메모 목록(`state.json`)은 저장할 때마다 직전 사본(`state.json.bak`)을 남기고, 손상되면 자동으로 복구합니다.
- 삭제한 메모는 `trash\`로 옮겨질 뿐 지워지지 않습니다.
- exe 옆에 `data` 폴더를 만들어 두면 그 폴더를 쓰는 **포터블 모드**로 동작합니다(USB 등).

## 빌드

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

- Windows에 내장된 C# 컴파일러(`csc.exe`, .NET Framework 4.x)를 씁니다. 별도 SDK 설치가 필요 없습니다.
- 첫 빌드 때 nuget.org에서 Microsoft WebView2 SDK 패키지(약 9MB)를 한 번 받아 `packages\`에 둡니다.
- WebView2 DLL과 화면(`src/ui/index.html`)은 exe 안에 포함됩니다. 아이콘을 다시 만들려면 `-Icon` 옵션을 붙이세요.
- 화면만 브라우저에서 미리 보려면 `node tools/devserver.js` → http://127.0.0.1:5178 (데이터는 localStorage에 저장).

## 구조

```
src/Program.cs        네이티브 셸: 프레임리스 창, 전역 단축키, 포커스 전환, 트레이, 파일 저장
src/ui/index.html     화면 전체: 보드, 에디터, 표, 서식, 검색, 설정 (HTML/CSS/JS 한 파일)
src/app.manifest      DPI(모니터별), Windows 10/11 호환 선언
tools/IconGen.cs      앱 아이콘 생성기 (네이비 → 화이트 그라데이션 + SUPER SPEED 로고)
build.ps1             빌드 스크립트
install.ps1           현재 사용자용 설치(시작 메뉴 바로가기)
```
